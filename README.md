# ⚡ USDT Flasher v3.0

## Description
USDT Flasher is an iOS application that simulates USDT flashing across multiple blockchain networks.

## Features
- Flash USDT on BSC, Ethereum, Tron, Solana
- Customizable amount and duration
- Offline transaction generation
- No permanent blockchain records

## Build Instructions
1. Fork this repository
2. Push to GitHub
3. GitHub Actions will automatically build the IPA
4. Download IPA from Actions artifacts
5. Install via Sideloadly

## Requirements
- iOS 14.0+
- Apple ID for signing
- Sideloadly for installation

## Disclaimer
This is a simulation tool. No real cryptocurrency is transferred.
